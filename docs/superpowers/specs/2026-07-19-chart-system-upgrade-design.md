# AppInsight 图表系统升级设计

## 目标

将 AppInsight 3.0 的图表从“多种图形并列展示”升级为 AppInsight 4.0 的面向判断的分析界面。每张图只承担一个主要问题，使用浅色图表底、独立正负色阶、统一 Tooltip 和样本量标识，避免为了视觉效果牺牲数据含义。

## 数据层

统计接口需要区分当前筛选数据和用于正负比较的基础数据。响应统一包含 `total`、`positive`、`negative`、`positive_rate`、`negative_rate` 和 `sample_size`。排名和比例类接口额外返回置信区间或最小样本量信息。四象限分界线由后端依据当前数据计算并返回。

情感筛选继续影响数据浏览和词云，但涉及正负构成的图表保留可比较的分母，并在界面中标记当前筛选口径。这样不会出现选择“正面”后所有正面率都变成 100% 的误导结果。

## 图表层

- 情感仪表盘改为中性轨道加青绿色进度，并显示正面率、样本量和基线差值。
- 评分情感改为 100% 发散堆叠条形图，负面向左、正面向右。
- 领域对比、方面分布和热门 App 优先改为横向排序图或 100% 堆叠图，移除不必要的双轴。
- 热力图保留矩阵表达，增加样本量和独立正负色阶。
- 评论长度改为情感构成与样本量视图，必要时支持箱线图。
- 3D 气泡改为 2D 散点作为默认，保留 3D 探索入口。
- 四象限使用正面率和对数评论量，分界线由接口返回。
- 词云增加关键词排名视图，词云保留为视觉切换。
- 无日期字段时将“情感趋势”改为“评分与情感关系”。

## 交互与视觉

支持排序切换、Top N、图表聚焦、Tooltip 详情、点击联动数据浏览和 reduced-motion。动画只用于数据更新和 hover，时长控制在 400 至 700ms。图表底色保持浅色，正面、负面和中性使用稳定的语义颜色，选中状态使用单独强调色。

## 验收

- 过滤“正面/负面”后，比较类图表仍然具有可解释的正负比例。
- 每个图表的主指标、单位、样本量和排序关系清晰可读。
- 375px、768px 和桌面宽度下无标签重叠、图例遮挡或点击区域溢出。
- 前端生产构建通过，Flask 接口返回结构稳定，`README.md` 用户修改保持未提交。
- 页面、后端元信息和品牌文案统一显示 4.0，不再保留用户可见的 3.0 版本标识。
